# Triage Labels

Default triage vocabulary:

| Role | Label |
|---|---|
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter / more context | `needs-info` |
| Fully specified and ready for an AFK agent | `ready-for-agent` |
| Needs human implementation/review | `ready-for-human` |
| Will not be actioned | `wontfix` |

If these labels do not exist in GitHub yet, create them only when needed.
