# Issue Tracker

Scrolls uses GitHub Issues on `oojBuffalo/scrolls` as the default issue tracker.

Use `gh issue` commands when issue creation, triage, or lookup is needed.

Guidelines:

- Keep issues small and independently actionable.
- Prefer vertical slices over component-only chores.
- Include acceptance criteria and verification commands.
- Link related commits/branches when available.
- For unattended automation, create issues only when they clarify future work; do not spam the tracker for every small commit.
