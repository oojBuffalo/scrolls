# Architecture Decision Records

One short record per consequential decision, written when the decision is
made (see `docs/agents/domain.md`). All records below are accepted and
implemented on this branch; `docs/architecture.md` describes the system
they add up to.

| ADR | Decision | Consequence in the code |
| --- | --- | --- |
| [0001](0001-implementation-stack.md) | Python ≥3.11 + uv, src layout, stdlib-first dependencies | `pyproject.toml`; per-adapter deps must pay their way |
| [0002](0002-first-fetch-adapter-wikipedia.md) | First fetch adapter is Wikipedia via the MediaWiki action API | fixed the adapter contract: `ScrollItem -> ScrollItem`, `FetchError`, stage `detected → fetched` |
| [0003](0003-youtube-adapter-oembed-transcripts.md) | YouTube via keyless oEmbed + optional transcripts, not yt-dlp | caption-less videos degrade to metadata-only scrolls |
| [0004](0004-rules-classification-engine.md) | Classification starts with a deterministic rules engine | `rules-v1`; unmatched items stay unclassified for a future LLM engine |
| [0005](0005-deterministic-kb-compiler.md) | KB compiler is a deterministic frontmatter rollup | `library/` rebuilt from scratch each run; concept pages merge by slug |
| [0006](0006-agent-install-stays-in-library-root.md) | `agent install` writes only under the library root | never edits `~/.claude` or other tools' config trees |
| [0007](0007-github-adapter-topics-as-concepts.md) | GitHub via keyless REST; repo topics become concepts | first `concepts` producer; `GITHUB_TOKEN` lifts the rate limit |
| [0008](0008-arxiv-adapter-atom-abstracts.md) | arXiv via the Atom export API; abstract becomes the summary | taxonomy codes go to `tags`; name mapping deferred |
| [0009](0009-fieldtheory-import.md) | X bookmarks arrive via Field Theory import, not native sync | `import fieldtheory`; JSONL lines preserved in `raw_text`; ids dedupe against `scrolls add` |
| [0010](0010-arxiv-pdf-full-text-pypdf.md) | arXiv PDF full text extracted inline with pypdf | PDF failure degrades to the abstract-only scroll |
| [0011](0011-media-capture-command.md) | Media capture is an explicit `scrolls media` command, not part of fetch | media refs gain a root-relative `path`; `media/` tree is cache, not canon |
| [0012](0012-arxiv-taxonomy-names-as-concepts.md) | arXiv taxonomy display names become concepts via a bundled table | papers join the KB concept graph; codes stay in `tags`; supersedes 0008's deferral |
| [0013](0013-generic-pdf-adapter.md) | Generic PDF URLs get a fetch adapter via pypdf | every detected source except `x` now fetches; the binary is the raw record (media ref + content hash), not `raw_text` |
| [0014](0014-mcp-server.md) | `scrolls mcp` serves the library over stdio via the official MCP SDK | tools wrap the same engines as the CLI; ingest chain extracted to `src/scrolls/pipeline.py`; SDK imported lazily |
| [0015](0015-llm-classification-engine.md) | LLM classification is an explicit opt-in: `classify --engine llm` via the Anthropic SDK | fills `domain` + merges `concepts`; structured outputs pin the category vocabulary; missing credentials abort the batch |
| [0016](0016-config-toml-classify-section.md) | `config.toml` is read, starting with the `[classify]` section | `default_engine` + `llm_model`; flag/env overrides always win; malformed config errors honestly; only the CLI loads config |
| [0017](0017-feed-subscriptions-sync.md) | Sync is feed subscriptions, not per-platform sync commands | `follow`/`unfollow`/`sync` over RSS/Atom via stdlib; `subscriptions` table (schema v4); sync registers at `detected`, adapters still fetch |
| [0018](0018-user-overrides-scrolls-set.md) | User overrides are `scrolls set`, free-form and clearable | IDEAS.md §8 layer three; engines' fields only; empty value clears; all-or-nothing parsing; no override bookkeeping |
| [0019](0019-feed-http-caching.md) | Feed polling uses HTTP conditional GETs | `etag`/`last_modified` on subscriptions (schema v5); 304 → status `unchanged`; follow never seeds the cache — only a full sync stores validators |
| [0020](0020-mcp-feed-subscriptions.md) | The MCP server exposes feed subscriptions | `follow_feed`/`unfollow_feed`/`list_feed_subscriptions`/`sync_feeds`; batch semantics shared with the CLI via `feeds.sync_many` |
| [0021](0021-feed-entry-published-dates.md) | Feed entry dates seed `published_at`, normalized to UTC ISO 8601 | RSS `pubDate`/Atom `published`-else-`updated`; adapters' own date wins, seed is the fallback; unparseable dates become None |
| [0022](0022-batched-llm-classification.md) | Batched LLM classification is `classify --engine llm --batch` via the Message Batches API | same engine, half the per-token price; block-and-poll, no persisted batch state; per-request failures fail their item, whole-batch failures abort |
| [0023](0023-url-normalization-item-identity.md) | URLs are normalized at registration; the normalized form is identity and storage | `normalize_url` strips tracking params/fragments/default ports before hashing; `related` matches raw + normalized; feed subscription URLs untouched; closes ADR 0017's identity quirk |
| [0024](0024-uniform-published-at.md) | `published_at` is UTC ISO 8601 from every writer | shared `dates.to_utc_iso`; adapters normalize source dates, unparseable ones degrade to the seed; date-only becomes midnight UTC; closes ADR 0021's dialect note |
| [0025](0025-llm-concept-summaries.md) | LLM concept summaries are stored data the deterministic compiler includes | `kb --engine llm` fills a `concept_summaries` store (schema v6); members fingerprint makes reruns free; 2+ scroll concepts only; shared LLM transport extracted to `scrolls/llm.py`; closes ADR 0005's open slot |
| [0026](0026-doctor-command.md) | `scrolls doctor` diagnoses index/file-tree drift; `--fix` repairs only what is safe offline | merges pre-normalization duplicates into the canonical id (atomic `replace_items`), rewrites missing scrolls, rebuilds FTS; missing media and orphan scrolls are report-only; exit 0 = fully consistent; closes ADR 0023's open migration debt |
| [0027](0027-rm-command.md) | `scrolls rm` removes items — row, scroll file, captured media — files first, row last | id-or-URL refs resolved like `add` mints ids; root-escape guard before any deletion; no tombstone (a still-followed feed re-registers); not exposed over MCP |
| [0028](0028-item-refs-accept-urls.md) | Every item-id argument accepts the item's URL | `pipeline.resolve_item_id` shared by all id-taking commands; misses report the resolved id `(from <url>)`; subscription ids separate; MCP deferred; generalizes ADR 0027's rm handles |
| [0029](0029-google-takeout-import.md) | YouTube history arrives via Google Takeout import, at stage `detected` | spine-only archive: watch time → `saved_at`, never `published_at`; repeat watches collapse to earliest; ads/deleted/non-video entries counted, never fatal; zip, directory, or the JSON file itself |
| [0030](0030-browser-bookmarks-import.md) | Browser bookmarks arrive via Netscape-HTML import, folders become tags | heterogeneous spine: every http(s) URL detects like `add`; folder ancestry → `tags` (root containers excluded), never `category`; earliest `ADD_DATE` wins, tags union; stdlib HTMLParser token stream; bookmarklets/`place:` counted, never fatal |
| [0031](0031-hacker-news-adapter.md) | Hacker News via the keyless Firebase API; link posts degrade to metadata-only | host→`hackernews`, only `/item?id=` fetches; text posts → body + lead summary, link posts → "N points, M comments"; article URL bare in `links`; Show HN → project, Ask HN unclassified; `kids` kept in `raw_text` |
| [0032](0032-batched-concept-summaries.md) | Batched concept summaries are `kb --engine llm --batch`; the Message Batches transport moves to the shared `llm.py` | `anthropic_complete_batch(…, *, schema, max_tokens)` shared by both LLM engines; positional `concept-<i>` ids; per-concept failures still compile, whole-batch failures abort; classify's wrapper re-tags errors; closes the architecture doc's open next step |
| [0033](0033-stack-exchange-adapter.md) | Stack Exchange via the keyless API; one adapter for the whole network, question + top answers, tags as concepts | host→`stackexchange` with `<site>:<id>` source_id; questions only fetch; answers optional second GET, accepted answer leads; tags → `concepts`; weak default `reference` (title rules win); eighth keyless adapter |
| [0034](0034-pypi-adapter.md) | PyPI via the keyless JSON API; identity is the PEP 503 name, keywords as concepts, classifiers as tags | host→`pypi` with normalized-name source_id (version-page dedupes); fetch resolves latest release; description → searchable text; keywords → `concepts`, classifiers → `tags`, project URLs → `links` (package↔repo edge); curated `pypi → tool`, first rule to produce `tool`; ninth keyless adapter |
| [0035](0035-npm-adapter.md) | npm via the keyless registry; README from the packument or, when empty, its tarball | host→`npm` with verbatim (case-sensitive) name source_id, scoped names and version-page dedupe; fetch resolves `dist-tags.latest`; README two-tier (packument `readme`, else capped `dist.tarball` extract — `http.get_bytes` gains `max_bytes`); keywords → `concepts`, no classifier analog so `tags` empty; homepage + normalized repository → `links` (package↔repo edge); `npm → tool`; tenth keyless adapter |
| [0036](0036-crates-io-adapter.md) | crates.io via the keyless JSON API; README from the `.crate` tarball | host→`crates` with folded (case-insensitive, `-`≡`_`) name source_id (version-page dedupes, like PyPI's PEP 503); fetch resolves `default_version`, reads canonical name back; README always from the capped `.crate` tarball (reuses npm's `max_bytes`); keywords → `concepts`, curated category taxonomy → `tags`; homepage/docs/normalized repository → `links` (crate↔repo edge); `crates → tool`; eleventh keyless adapter |
| [0037](0037-crossref-doi-adapter.md) | Crossref via the keyless DOI metadata API; the published-literature sibling of arXiv | host `doi.org`/`dx.doi.org`→`crossref` with the DOI folded lowercase as source_id (case-insensitive, dedupes the legacy resolver); fetch reads `api.crossref.org/works/<doi>`; JATS abstract stripped to a plain `summary`, no `extracted_text` (no full text); `subject` → `concepts`, `type`+venue → `tags`; only `resource.primary.URL` → `links`, `reference` DOIs dropped; date precedence `issued`→…→`created`; `crossref → paper` like arXiv; twelfth keyless adapter |
| [0038](0038-arxiv-published-doi-link.md) | arXiv records its published DOI as a link — the preprint↔published edge | the `arxiv:doi` Atom element becomes a `https://doi.org/<doi>` link (arXiv previously emitted no `links`); `related` folds it to the `crossref:<doi>` id across the DOI case fold, wiring a preprint to its published paper both ways with no new edge type or schema change; no DOI → empty links; `arxiv:journal_ref` stays in `raw_text` |
| [0039](0039-packagist-adapter.md) | Packagist via the keyless JSON API; the PHP/Composer sibling of pypi/npm/crates | host→`packagist` with the `vendor/name` folded lowercase (case-insensitive, two-segment, version-page/`.json`-strip dedupe); fetch ranks `versions` by the numeric core of `version_normalized`, highest stable wins (no `default_version` pointer, no comparator dependency); no README in the API → metadata-only, description → `summary`; keywords → `concepts`, `type`+SPDX licenses → `tags`; repository/homepage/git-source → `links` (package↔repo edge); `packagist → tool`; thirteenth keyless adapter |
| [0040](0040-rubygems-adapter.md) | RubyGems via the keyless JSON API; the Ruby sibling of pypi/npm/crates/packagist | host→`rubygems` with the gem name verbatim (case-sensitive registry, npm's rule; version-page dedupe); `gems/<name>.json` returns the latest version inline (no `versions` collection, no comparator); no keywords → `concepts` structurally empty, no README → metadata-only with `info` → `summary`; SPDX licenses → `tags`; homepage/source/docs URIs → `links` (gem↔repo edge survives a tagged-tree source URI); `rubygems → tool`; fourteenth keyless adapter |
| [0041](0041-huggingface-hub-adapter.md) | Hugging Face Hub via the keyless API; one adapter for models + datasets, the arXiv tag as a cross-source link | host→`huggingface` (also `hf.co`) with the repo kind in the source id (`model:`/`dataset:`, Stack Exchange's one-adapter-many-kinds), id verbatim (case-sensitive), two-segment + subpage dedupe, reserved-path table; fetch routes on kind, card README (frontmatter stripped) → `extracted_text` + lead-paragraph `summary`, degrades to metadata-only; concepts from structured fields (`pipeline_tag`/`task_categories` + `cardData.tags`), not the flat tag soup; `library_name`+license → `tags`; `arxiv:`→arxiv.org link (model↔paper edge, ADR 0038 kin), `dataset:`→Hub link (model↔dataset edge); `model → tool`, `dataset → dataset`; fifteenth keyless adapter |
| [0042](0042-go-modules-adapter.md) | Go modules via the keyless `proxy.golang.org`; the last registry on the JSON-metadata pattern | host `pkg.go.dev`→`go` with the module path verbatim (case-sensitive; module = everything before `@`, so a versioned sub-package dedupes; first segment must be a domain, so stdlib/site routes carry no fetchable module); fetch case-encodes the request (`X`→`!x`), `/@latest` → version+time+`Origin`, `/@v/<v>.mod` → the go.mod as searchable `extracted_text` (the sparsest adapter: no description so `summary` None, no keywords so `concepts=()`, no license/classifier facet so `tags=()`); repo link from `Origin.URL` (the only truth for a vanity path) else derived from the module path for known VCS hosts (package↔repo edge); `go → tool`; degrades to metadata-only; sixteenth keyless adapter, completing the registry family |
| [0043](0043-huggingface-spaces-subadapter.md) | Hugging Face Spaces as a third repo kind on the Hub adapter | `detect_source` adds a `spaces/<org>/<name>`→`space:<id>` branch (the dataset branch's twin); a `_PATH_SEGMENT` kind→segment map drives the `/api/spaces` endpoint, site prefix, and card URL (replacing the two-way dataset ternaries); `sdk` fills the `tags` facet (`library_name`'s slot), `cardData.title` the title (`pretty_name`'s slot), `cardData.tags` the concepts; `cardData.models`/`datasets` → space↔model/dataset links surviving a card-less degrade; `space → tool` like a model; model/dataset behavior byte-unchanged; extends ADR 0041 |
| [0044](0044-link-graph-command.md) | `scrolls graph` — the cross-item link graph the adapters built, materialized as a first-class view | new `graph.py` extracts the link-resolution primitives (`link_tokens`, `identity_tokens`) out of `related.py` (which becomes a byte-identical wrapper, one definition for the per-item and whole-library views); `build_graph` indexes every item's identity tokens once then probes with each link (linear, not the per-pair O(n²)); directed edges `from→to` with the matching link as `via`, parallel links collapse, self-links drop, connected nodes by default (`--all` for isolates); `to_payload` `{nodes, edges, stats}` shared by `scrolls graph` and the MCP `get_link_graph` tool; no network, no model, empty library → empty graph; edges intentionally untyped this slice (relation labels, a KB `graph.md` page, concept/tag edges deferred) |
| [0045](0045-datacite-doi-fallback.md) | DataCite via a fetch-time fallback on the same `doi.org` detection — datasets/software join the published literature | a `doi.py` dispatcher backs `FETCH_ADAPTERS["crossref"]`: try `crossref.fetch_item`, fall back to `datacite.fetch_item` on its `FetchError` (a DataCite-only DOI 404s against Crossref), raise naming both if neither holds it; the registration agency can't be read off the URL and `crossref:<doi>` identity is fixed at `add` time (the ADR 0038/0041 edges depend on it), so the source stays `crossref` and `provenance.adapter="datacite"` tells the truth; `datacite.py` maps the JSON:API `attributes` (titles+subtitle, creators "Given Family", `Abstract` description → `summary` no full text, `subjects` → `concepts`, DataCite date precedence, `resourceTypeGeneral`+`resourceType`+publisher → `tags`, landing + container-DOI `links`); the resource type rides in `provenance.resource_type` so `classify.py` maps it (`Dataset → dataset`, `Software`/`Model` → `tool`, `Text`/article types → `paper`, `Image`/`Sound` → `media`, ambiguous types unclassified) — Hugging Face's repo-kind read (ADR 0041) but a fetch-time fact, not a detection-time one; first two fetch adapters on one detected source; `x` stays the only adapterless source |
| [0046](0046-lobsters-adapter.md) | Lobsters via the keyless JSON API; the whole discussion in one request | host `lobste.rs`→`lobsters` with the `/s/<short_id>` short id verbatim (slug stripped; `/c`,`/t`,`/u`,front pages carry no fetchable story — HN/SE's pattern); a story's `.json` returns submission + tags + the entire comment thread in *one* request (HN defers comments, SE spends a second GET), `description_plain`/`comment_plain` already plain so no HTML grammar; body + comments (deleted/moderated skipped, bylined like SE answers) → searchable `extracted_text`, all comments kept (free, no cap); link submission's article → bare `links` (HN link-story pattern), text submission's body the searchable content; `summary` = body lead else `"N points, M comments"`; tags → `concepts` (github-topics pattern); **no category default — unclassified like Hacker News**, not SE's weak `reference` (a heterogeneous aggregator entry); raw story (comment `depth` included) kept in `raw_text`; honestly keyless where Reddit's `.json` now 403s; seventeenth keyless adapter |
| [0047](0047-context-connected-scrolls.md) | `scrolls context` surfaces connected scrolls from the link graph | a "Connected scrolls" section between Excerpts and Links lists items linked to/from the matches (`graph.build_graph`, the same edges `scrolls graph` reports) but not themselves keyword hits; link-only (concept/tag signal deferred); ranked by centrality then best-match rank then id, capped at the match count; direction names the match ("links to"/"linked from", `+N more`); conditional (no edges → no section); titles from the graph's nodes, no extra `get_item`; flows to the MCP `get_context_bundle` for free; the cross-source edges of ADRs 0034–0046 finally surface in the bundle an agent reads |
| [0048](0048-bluesky-adapter.md) | Bluesky via the keyless AppView; the open social post X could never be | host `bsky.app`→`bluesky` with `<actor>/<rkey>` source_id (actor folded lowercase — handle/DID are case-insensitive — rkey verbatim; profile/feed/list/home routes carry no fetchable post); a handle URL costs one `resolveHandle` GET for the DID the AT-URI needs (the SE/HF two-request shape), a `did:` URL skips it; one `getPostThread` returns the post + its nested reply tree; post text + bylined replies (deleted/blocked/empty skipped) → searchable `extracted_text`, image alt text is the body of a textless post; external card / quoted post / inline `#link` facets → `links` (post↔post and cross-source edges, ADR 0044), images → `photo` media (`@jpeg`→`.jpg` via the existing fallback), `#hashtag` facets → `concepts` (github-topics pattern); synthesized title, `summary` = lead else alt else card title else "N likes, M reposts, K replies"; **no category default — unclassified like Hacker News/Lobsters**; whole thread in `raw_text`; eighteenth keyless adapter, the deferred social-post source (IDEAS.md §6) reached on the open network |
