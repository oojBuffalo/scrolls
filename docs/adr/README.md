# Architecture Decision Records

One short record per consequential decision, written when the decision is
made (see `docs/agents/domain.md`). All records below are accepted and
implemented on this branch; `docs/architecture.md` describes the system
they add up to.

identity folds lowercase (`_nuget_id` validates alphanumeric runs joined by single `.`/`-`/`_`, claims `nuget.org`/`www.`, version pages deduping, list/`/profiles`/`/stats`/search → no fetchable item) — the **forgiving** fold (PyPI/crates/pub/Hex rule ADR 0034/0036/0088/0089), since NuGet ids are case-insensitive *and* the flat-container path requires lowercase, the registrant's display casing (`Newtonsoft.Json`) read back from the nuspec `<id>` for title+canonical URL (crates' read-back); latest **stable** version selected by Packagist's comparator-free numeric ranking (ADR 0039 — the top version is often a pre-release, live `newtonsoft.json` → `13.0.5-beta1`), pre-release pool the fallback; the nuspec parsed **namespace-agnostically** (the namespace URI varies by schema generation — `…/2011/08/`, `…/2013/05/`, … — so children matched by *local* name, the one rule that reads every nuspec); **`<tags>` → `concepts`** (whitespace/comma/semicolon split, the github-topics/PyPI-keywords role ADR 0007/0034 — the .NET ecosystem joining the KB concept graph, the payoff a `web` scrape never gave), `<description>` else `<summary>` → `summary` with **no `extracted_text`** (the README ships in the `.nupkg` — honestly metadata-only, RubyGems/Hex ADR 0040/0089), SPDX `<license type="expression">` → the one `tag` (a `type="file"` is a filename, skipped — the pub/Hex license facet), `<projectUrl>` + `<repository url>` → `links` (`.git`/`git+` folded, the **package↔repo edge** resolving to a saved github repo); the nuspec **is** the metadata so its failure is a FetchError (no metadata-only scroll to degrade to, unlike Go's optional go.mod); `nuget → tool` (ADR 0004); the **ninth** keyless registry (the family now spans Python/JS/Rust/PHP/Ruby/Go/Dart/Elixir/.NET), live-verified (`Polly` BSD-3-Clause+deduped link, `Newtonsoft.Json` `<title>Json.NET</title>`+MIT+repo edge to `JamesNK/Newtonsoft.Json`, `Serilog` Apache-2.0); defers the `.nupkg` README, package-type tags (`DotnetTool`), the registration publish date, and self-hosted feeds; Hackage/CPAN remain reachable on the same pattern, none claimed until a saved URL needs one |
